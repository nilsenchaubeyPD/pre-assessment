# Pre-Assessment Flow

Redesigned Topin candidate pre-assessment flow: a clickable, working prototype of everything
a candidate sees from opening the test link to pressing "Start test".

Built as a React + TypeScript + Tailwind app with a simulated device layer so every edge case
(camera/mic/face/screen-share/fullscreen/network failures, gate states, SEB, consent, etc.)
is demonstrable without real hardware permissions.

Status: scaffolding in progress.
